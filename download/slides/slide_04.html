The architecture is intentionally layered so that each concern can be tested, audited, and improved in isolation. Layer one is ingestion — receipts, CSV imports, manual entry, all normalized to a single ledger schema backed by Prisma and SQLite. Layer two is categorization — LLM-assisted with rule fallback, mapping merchants to canonical categories with explicit confidence scores. Layer three is the agent: a supervisor–worker pattern where an LLM supervisor parses the user's intent, plans the tool sequence, dispatches to specialized workers, and validates results. Below the supervisor sit eleven tools — seven read, four write — every one of them permissioned. Layer four is insight: the Financial Health Score, Holt-Winters cash flow forecast, Monte Carlo simulation, behavioral triggers, and more, surfaced across eight user-facing views. This separation is what lets us add new analytics without touching the agent, and new agent skills without touching the analytics.
