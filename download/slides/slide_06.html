This is the agent in action. The chat on the left is a real transcript from our demo. The user says, "I spent forty-two dollars on groceries at Trader Joe's." The supervisor parses the intent, plans the call, dispatches to the ledger worker, which calls add_transaction. The transaction is logged, the budget envelope is updated, and the agent responds with the new context — all in well under a second. The same pattern holds for creating goals and updating budgets. Every write tool is permissioned, audited, and reversible. On the right you see the full tool inventory: eleven tools, split seven read and four write. Read tools query the ledger, budgets, goals, health score, forecasts, analytics, and insights. Write tools add transactions, create goals, update budgets, and set permissions. This is the surface area the agent can reason over.
